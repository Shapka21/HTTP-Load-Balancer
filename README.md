# HTTP-Load-Balancer

HTTP-Load-Balancer — это простой и расширяемый балансировщик нагрузки, реализованный на языке Go. Он распределяет входящие HTTP-запросы по пулу бэкенд-серверов с поддержкой:

 - Round-Robin алгоритма маршрутизации

 - Reverse proxy (`httputil`)

 - Health-checks

 - Rate limiting на основе алгоритма Token Bucket

 - Горутин и потокобезопасной обработки

 - Конфигурации через внешний JSON-файл

 - Docker/Docker Compose для развёртывания

## Функциональность
### Балансировщик нагрузки
 - Алгоритм: Round-Robin
 - Переадресация запросов через httputil.ReverseProxy
 - Проверка доступности бэкендов (`/health`)
 - Автоматическое исключение недоступных бэкендов

### Rate Limiting
 - Реализация алгоритма Token Bucket
 - Индивидуальные лимиты по IP-адресу
 - Поддержка ручного добавления клиентов через /addUser
 - Получение информации о клиентах через /getUser
 - Возможность настройки стандартных лимитов

### Конкурентность
 - Потокобезопасная работа с мьютексами
 - Параллельная обработка запросов с использованием горутин

### Конфигурация
 - Используется внешний JSON-файл (`config.json`)
 - Возможность горячей подмены конфигурации через том в Docker

```
  ]

```

## API эндпоинты


| Метод | URL         | Описание                                     |
|-------|-------------|----------------------------------------------|
| CRUD   | `/`         | Проксирование запроса на один из бэкендов   |
| GET   | `/getUser`  | Получение информации о лимитах клиента       |
| POST  | `/addUser`  | Добавление клиента и его лимитов             |

Пример POST-запроса на добавление клиента:
```
POST /addUser
{
  "capacity": 100,
  "rate_per_sec": 10
}
```
